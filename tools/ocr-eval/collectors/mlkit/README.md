# ML Kit collector

Reads the M2-01 golden corpus with ML Kit Text Recognition v2 and writes the same
`<engine>.json` every other collector writes (ADR-014). It does no scoring: four engines
in four languages, one scorer, or the numbers are not comparable.

## Why this is a standalone Gradle project

ML Kit runs on a device, so the only honest way to drive it is an Android **instrumented**
test. It cannot live in the Expo app's `android/` directory: that tree is generated by
`expo prebuild --clean` on every CI run and is git-ignored, so anything added there is
deleted before it runs.

It should not live there anyway. The harness measures the **engine**, not our capture
pipeline — the same reason M2-05a deliberately does not depend on M2-02 or M2-03. A test
inside the app would measure ML Kit *plus* whatever the app does to an image first, and
when the number moved nobody could say which half moved.

## How it runs

```
./gradlew :collector:connectedAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.corpus=/sdcard/ocr-corpus
```

The corpus is pushed to the device with `adb push`, the test writes its readings to the
app's external files directory, and CI pulls the JSON back out. The test is the collector;
there is no app.

## Versions

Every version here came from Google's Maven repository rather than from memory
(`dl.google.com/dl/android/maven2/.../maven-metadata.xml`), which matters more than usual:
Maven Central carries a stale `com.android.tools.build:gradle` whose "latest" is **2.3.0**,
nearly a decade behind the real AGP, and a plausible wrong version here fails as a
confusing Gradle resolution error rather than as "that does not exist".

| What | Version | Why this one |
| --- | --- | --- |
| `com.google.mlkit:text-recognition` | 16.0.1 | current release; the bundled model, so nothing downloads at runtime |
| AGP | 9.4.1 | latest **stable**; the repository's `release` marker points at `9.5.0-alpha08` and this project does not take alphas |
| `androidx.test.ext:junit` | 1.3.0 | current release |
| `androidx.test:runner` | 1.7.0 | current release |
| Gradle | 9.3.1 | matches what `expo prebuild` generates for the app, so CI caches one distribution rather than two |

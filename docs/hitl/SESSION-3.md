# Session 3 — Handwrite and photograph 15 song lists

**About 25 minutes. Due during M2.** This is the only test data that can honestly
prove the handwriting targets: synthetic handwriting rendered from fonts is far
cleaner than the real thing, so a model that passes on synthetic images can still fail
on a real photo of a real page.

The lists are **generated by Claude Code from the seed catalog**, so the ground truth
is known before you write anything. You are producing images, not transcriptions —
there is nothing to type up afterwards.

---

## 1. Get the lists

Open `golden/handwriting/ASSIGNMENTS.md`. It contains 15 short lists, each 8-15 songs,
with some lines marked **cross this one out**.

## 2. Write them out (15 min)

- **Vary things deliberately.** Different pens (biro, gel, pencil), different paper
  (lined, blank, squared, a napkin). Variety is the point; neatness is not.
- **Write naturally.** Do not print carefully — the app has to cope with your actual
  handwriting.
- **Cross out the marked lines** the way you normally would: a single strike, a
  scribble, whatever is natural. Crossed-out detection (FR-M-009) is measured against
  these.

## 3. Photograph each page twice (7 min)

1. Once in **good light**, page flat, roughly square on.
2. Once **dim, at an angle, or slightly blurred** — the realistic case.

Phone camera is correct. Do not scan them; a flatbed scan is unrealistically clean.

## 4. Hand them over (3 min)

1. Put the photos in `golden/private/incoming/` — this folder is git-ignored.
2. Tell Claude Code they are there.

It encrypts them with `age` into `golden/private/`, deletes the plaintext, and wires
them into CI. The key is a GitHub secret, and decryption happens only in CI runs on
`develop` and `main`.

**The repository is public.** The plaintext photos must never be committed, which is
why the folder is ignored and the plaintext is deleted rather than kept "just in case".

## 5. Optional but worth it

Two or three friends doing five lists each makes the handwriting numbers considerably
more trustworthy — one person's handwriting is one data point, not a distribution.
If they help, note roughly how many writers contributed in the H3 issue; the report
cites it.

---

## Done

Close the H3 issue and type `/autopilot`.
